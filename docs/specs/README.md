# 研究范围与实验协议

[返回文档导航](../README.md)

本模块保存经过确认的研究范围、实验定义与验收条件。探索中的想法先放入 [wiki](../wiki/README.md)。

## 协议应说明什么

- 研究问题、假设、适用阶段和非目标。
- 改变的因素、保持不变的因素、对照和预算。
- 数据与任务规则、训练和评估划分、种子及指标定义。
- 参数选择方式、继续或停止条件，以及允许的解释范围。
- 协议状态、版本、确认日期和变更原因。

代码偏离协议时先列出差异，由用户决定修改代码或更新协议。保留旧运行所依据的版本，禁止看到结果后静默改写原假设。
