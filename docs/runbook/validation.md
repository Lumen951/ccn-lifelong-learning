## 执行前与执行后

执行方式沿用 [根说明](../../README.md) 和 [实验说明](../../experiments/README.md)，不复制命令以免不同步。
原梯度脚本会写临时目录；实验验证会在 results 下创建带随机前缀的验证运行并修改测试用产物。执行范围应先确认，不能称作纯只读检查。

每次验证记录日期、源码版本/差异、环境、实际调用、退出状态、输出位置、失败原因与适用限制。
未执行、通过、失败、受阻分别标记；旧 README 的 PASS 描述不等于当前环境已通过。
文档验证检查编码、链接、事实来源与 Git 差异，不启动算法测试。
