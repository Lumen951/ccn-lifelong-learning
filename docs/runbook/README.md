## 追踪原则

实验设计编号与实际运行编号分开；一个设计可以关联多个配置、种子和运行目录。
登记应包含协议及版本、状态、代码版本与未提交差异、配置位置、种子、指标与检查点位置、失败或偏离协议的情况，以及结论的适用限制。
机器已记录的完整参数优先引用实际运行清单，不重复手抄。

结果目录被 Git 忽略。文档保存小型登记和证据索引，大型产物保留在实际位置；未确定的备份位置明确标记待确定，不声称已经归档。
