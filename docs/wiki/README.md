# 研究探索与文献理解

[返回文档导航](../README.md)

本模块保存尚未形成正式协议的研究问题、文献理解、可能解释和待验证假设。

## 记录规则

注明来源和日期，区分论文主张、代码观察、个人解释与候选方案。
记录反例、不确定性和失败解释；不得用激活统计直接替代因果贡献证据。
Obsidian 或聊天中的材料仅提炼与项目有关的内容，不整体复制个人知识库。

## 如何进入正式协议

探索方案成熟后，由用户确认研究范围和评估方式，再提炼进入 [specs](../specs/README.md)。保留来源链接及被替代说明，避免旧设想被误认为当前生效方案。

列活跃度、功能贡献、冻结及持续任务等候选问题已整理，见下方链接；本轮不确定具体消融方法、参数矩阵或训练预算。
